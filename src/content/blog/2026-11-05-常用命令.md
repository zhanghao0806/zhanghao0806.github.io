## 服务器常用

```bash
cd  /mnt/nfs/home/zhanghao/
ls -a 
# 显示隐藏文件
free -h
df -h .
# 列出当前目录下，每个文件夹占用多少；
du -sh */ 
mkdir -p folder_name
```

df: disk free;

du： disk usage ； -s：summary 不展开内部。

## Git命令

```bash
git init
git add .
git commit -m "initial commit"

git remote add origin https://github.com/zhanghao0806/example.git
git branch -M main # 本地主分支设置为 main 和 GitHub 一样
git push origin main
```

Github 新建仓库默认主分支是 main；



MAC关机

```bash
sudo shutdown -h now
sudo shutdown -r now
```

h:halt  r:reboot
