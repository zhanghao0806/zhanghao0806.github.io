**实验设置：**

固定 QSD 流程与 Agent 驱动的工具编排流程; (Agent依然可以用 QSD)

### baseline

QSD；

当前 baseline QSD 已经输出量子门线路，但这些门可能是 `U、CX、RZ、H`；本项目规定最终只能用 `RX、RZ、SX、X、CZ`。其中 `U、CX、H` ，需要进一步等价转换。

实验参数设置：config.yaml

固定门集： RX RZ SX X CZ

拓扑关系：3 个 qubit线性连接；

比较指标：酉矩阵相似度、CX 数量、电路深度、总门数；



### Agent 负责哪些

可调用的工具有什么？ AQC、diagonal、Clifford、Qserach、KAK、QSD；

**特征提取器提供哪些特征：**

重要。决定 Agent 能得到什么特征。

| 特征               | 含义                                 | 能影响什么决策              |
| ------------------ | ------------------------------------ | --------------------------- |
| `n_qubits`         | 输入矩阵对应的比特数量               | 能否使用 KAK、AQC           |
| `diagonal_error`   | 矩阵偏离对角矩阵的程度               | 是否使用 Diagonal Synthesis |
| `is_clifford`      | 是否属于 Clifford 酉矩阵             | 是否使用 Clifford Synthesis |
| `tensor_separable` | 是否能够写为小矩阵的张量积           | 是否先拆分子问题            |
| `identity_overlap` | 与单位矩阵的接近程度（忽略全局相位） | 是否值得尝试低深度近似电路  |
| `unitarity_error`  | 是否满足酉性条件                     | 输入是否合法                |
| `baseline_cx`      | QSD 的 CX 门数量                     | 其他候选需要改善的指标      |
| `baseline_depth`   | QSD 的电路深度                       | 其他候选需要改善的指标      |

## 文件位置

* 准备测试、提前生成的矩阵：unitary-agent-demo/results/exploration-validation-20261102/matrices样本类别是：M01 M02 ... M04； 想生成不同的M01，改随机种子即可；

* 评估：先检查准确性（相似度）、然后检查是否满足硬性要求、最后剩下来的按照CZ 数量、深度、总门数量的顺序选最优；

  相似度：
  $$
  F(U, V) = \frac{|\text{Tr}(U^\dagger V)|^2}{d^2} = \frac{|\text{Tr}(U^\dagger V)|^2}{64}
  $$
  这个函数是Qiskit提供的 酉矩阵相似保真度，有文献。A simple formula for the average gate fidelity of a quantum dynamical operation。
